# Contenido de `templates/`

- `README.md`: explica para qué sirve cada plantilla y subcarpeta de esta carpeta.
- `base.html`: estructura común de las páginas; contiene la navegación, los mensajes y el espacio donde se inserta el contenido de cada pantalla.
- `auth/`: plantillas para iniciar sesión; su README detalla sus archivos.
- `dashboard/`: plantillas para el panel principal; su README detalla sus archivos.
- `inventory/`: plantillas para las pantallas de inventario; su README detalla sus archivos.
- `payments/`: formularios para procesar pagos PSE; su README detalla sus archivos.
- `products/`: plantillas para las pantallas de productos; su README detalla sus archivos.
- `reseller/`: muestra precios mayoristas, compra de unidades, inventario propio y cálculo de ganancia sugerida.
- `sales/`: plantillas para las pantallas de ventas; su README detalla sus archivos.
- `wallet/`: muestra saldo, recargas PSE y movimientos de cartera.
- `users/`: plantillas para las pantallas de usuarios; su README detalla sus archivos.
